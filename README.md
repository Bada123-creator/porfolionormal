# Portfolio — Bada Diop
Site statique responsive, sans dépendances.

1. Créer un dépôt public GitHub nommé `portfolio-bada`.
2. Ajouter `index.html` à la racine du dépôt (Add file → Upload files).
3. Sur https://vercel.com/new importer ce dépôt, choisir Framework Preset: Other, laisser les commandes de build vides et cliquer Deploy.
4. Copier l'URL attribuée par Vercel et la remplacer dans le CV.

Avant publication, ajouter une adresse e-mail professionnelle et un lien LinkedIn exact dans la section Contact si souhaité. Aucun identifiant de contact fictif n'est inclus.
